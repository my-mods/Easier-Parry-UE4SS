DESCRIPTION (NEXUS BBCODE)
--------------------------
[center][size=5][b]Easier Parry - UE4SS[/b][/size]
[i]A configurable, lightweight way to make parrying more forgiving.[/i][/center]

[b]Overview[/b]

Easier Parry multiplies Coen's live parry timing window. It uses the value from
the running game as its baseline, so current difficulty adjustments are
preserved instead of being replaced with a fixed timing value.

The default multiplier is [b]2x[/b]. You can configure any value from 0.1x to
50x, and the mod automatically reapplies the setting when the player is
recreated or the game recalculates the attribute.

[b]Features[/b]

[list]
[*]2x parry timing window by default.
[*]Configurable multiplier from 0.1x to 50x.
[*]Preserves the live vanilla or difficulty-adjusted baseline.
[*]Automatically reapplies after player or attribute recreation.
[*]No PAK replacements or IoStore file conflicts.
[*]Optional diagnostic logging, disabled by default.
[*]UE4SS console commands for status, reload, toggle, and quick testing.
[/list]

[b]Requirements[/b]

[list]
[*]The Blood of Dawnwalker on PC.
[*]A working Dawnwalker-compatible UE4SS 3.x installation.
[/list]

Validated against Steam build 25129649 / Hotfix 1.0.3 / executable CL-257186.

[b]Vortex installation[/b]

Install the downloaded ZIP through Vortex, then enable and deploy it.

[b]Manual installation[/b]

Open the ZIP's [code]Data[/code] folder and copy [code]EasierParryUE4SS[/code]
into:

[code]The Blood of Dawnwalker\Dawnwalker\Binaries\Win64\ue4ss\Mods[/code]

The final script path should be:

[code]...\ue4ss\Mods\EasierParryUE4SS\Scripts\main.lua[/code]

[b]Configuration[/b]

Edit [code]EasierParryUE4SS\Scripts\EasierParryUE4SS.ini[/code]:

[code]
[General]
enabled = true
factor = 2.0
pollMilliseconds = 500
debugLogging = false
[/code]

[list]
[*][code]1.0[/code] is vanilla timing.
[*][code]1.5[/code] gives 50 percent more time.
[*][code]2.0[/code] doubles the timing window.
[*][code]3.0[/code] triples the timing window.
[/list]

Use [code]easierparry reload[/code] in the UE4SS console after changing factor
or enabled. Restart the game after changing the polling interval.

[b]Console commands[/b]

[code]
easierparry status
easierparry reload
easierparry off
easierparry on
easierparry 3
[/code]

The number command changes the multiplier for the current session without
editing the INI.

[b]Logging and verification[/b]

The mod writes one short [code]Loaded[/code] message and one successful
[code]Applied[/code] message. Continuous diagnostic logging is disabled by
default and can be enabled with [code]debugLogging = true[/code].

After loading a save, check:

[code]The Blood of Dawnwalker\Dawnwalker\Binaries\Win64\ue4ss\UE4SS.log[/code]

Look for an entry beginning with [code][EasierParryUE4SS] Applied x2.000[/code].

[b]Compatibility[/b]

Easier Parry replaces no packaged game assets, so it has no PAK or IoStore file
conflicts. It may conflict with another runtime mod that continuously changes
Coen's [code]ParryWindowMultiplier[/code].

[b]Uninstallation[/b]

Disable or remove the mod through Vortex. For a manual installation, delete only
the [code]EasierParryUE4SS[/code] folder from [code]ue4ss\Mods[/code], then
restart the game.
