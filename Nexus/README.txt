Nexus listing materials

Use metadata.json for the mod name, summary, version and download description.
Paste description.bbcode.txt into the Nexus description editor's BBCode mode.
Upload thumbnail.png separately as the mod's thumbnail/cover image.
The thumbnail uses an official in-game screenshot; see THUMBNAIL-SOURCE.md
for attribution and image rights.

These files are maintained in the repository's Nexus folder and excluded
from the Vortex release ZIP. The ZIP's vortex_override_instructions.json
supplies Vortex's stable name, version and short description.

Category and keywords are suggestions. Nexus IDs are unset because these
files do not create or identify a published Nexus listing.

Suggested support note: after loading a save, check UE4SS.log for an
[EasierParryUE4SS] Applied line. For troubleshooting, enable debugLogging
in the INI and include the relevant EasierParryUE4SS log entries.
