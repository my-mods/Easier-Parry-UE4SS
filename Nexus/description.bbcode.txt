[center][size=5][b]Easier Parry - UE4SS[/b][/size]
[i]A configurable, lightweight way to make parrying more forgiving.[/i][/center]

[b]Overview[/b]

Easier Parry multiplies Coen's live parry timing window. It uses the value from
the running game as its baseline, so current difficulty adjustments are
preserved instead of being replaced with a fixed timing value.

The default multiplier is [b]2x[/b]. You can configure any value from 0.1x to
50x, and the mod automatically reapplies the setting when the player is
recreated or the game recalculates the attribute.

[b]Features[/b]

[list]
[*]2x parry timing window by default.
[*]Configurable multiplier from 0.1x to 50x.
[*]Preserves the live vanilla or difficulty-adjusted baseline.
[*]Caches player/attribute references and checks once per second by default.
[*]No global object searches or redundant writes while the cache is healthy.
[*]Reacquires invalid references after loading or recreation.
[*]No PAK replacements or IoStore file conflicts.
[*]Optional diagnostic logging, disabled by default.
[*]UE4SS console commands to view, change and save the selected settings.
[/list]

[b]Requirements[/b]

[list]
[*]The Blood of Dawnwalker on PC.
[*]A working Dawnwalker-compatible UE4SS 3.x installation.
[/list]

Targets Steam build 25129649 / executable CL-257186. The v1.0.2 performance fix has passed simulated Lua and package checks; in-game frame-time validation is pending.

[b]Vortex installation[/b]

Install the downloaded ZIP through Vortex, then enable and deploy it.

For updates, close the game, replace/reinstall the existing entry through Vortex,
then deploy. Use [b]UE4SS (Lua mods)[/b] and keep one enabled Easier Parry entry.
The ZIP replaces the full INI: back up and reapply custom preferences.
Use [code]pollMilliseconds = 1000[/code] for the new default interval.

[b]Configuration[/b]

Edit [code]EasierParryUE4SS\Scripts\EasierParryUE4SS.ini[/code]:

[code]
[General]
enabled = true
factor = 2.0
pollMilliseconds = 1000
debugLogging = false
[/code]

[list]
[*][code]1.0[/code] is vanilla timing.
[*][code]1.5[/code] gives 50 percent more time.
[*][code]2.0[/code] doubles the timing window.
[*][code]3.0[/code] triples the timing window.
[/list]

The INI is read once at game startup. The selected factor stays active until you
change it through the console or exit the game. Death and save loading do not
reload settings. Missing settings use their defaults; factor defaults to 2.0.
Restart the game after direct INI edits. UTF-8 files with or without a BOM work.

[b]Console commands[/b]

[code]
easierparry status
easierparry off
easierparry on
easierparry 3
[/code]

The number command selects a multiplier and enables the mod. Number and on/off
commands save factor and enabled to the same INI for the next game start,
preserving other settings and comments. If saving fails, the selection remains
active for the current session and the log reports the failure.

[b]Logging and verification[/b]

The mod logs the loaded INI path and factor at startup, followed by an
[code]Applied[/code] message when it attaches to the player attribute. Continuous diagnostic logging is disabled by
default and can be enabled with [code]debugLogging = true[/code].

After loading a save, check:

[code]The Blood of Dawnwalker\Dawnwalker\Binaries\Win64\ue4ss\UE4SS.log[/code]

Look for an entry beginning with [code][EasierParryUE4SS] Applied x2.000[/code].

[b]Compatibility[/b]

Easier Parry replaces no packaged game assets, so it has no PAK or IoStore file
conflicts. It may conflict with another runtime mod that continuously changes
Coen's [code]ParryWindowMultiplier[/code].

[b]Uninstallation[/b]

Disable or remove the mod through Vortex, deploy, then restart the game.
