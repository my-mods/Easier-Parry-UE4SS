[b]Easier Parry - UE4SS[/b]
More forgiving parries, with native held-guard recovery after dodging. Attack inputs retain the base game’s guard behavior.

[b]Features[/b]
[list]
[*]Doubles the parry window by default. Choose any multiplier from 0.1x to 50x; difficulty adjustments are preserved.
[*]Held guard resumes after native dodge suppression ends, unless an attack or actual guard release has ended guarding.
[*]Personal settings stay separate from the mod and survive updates.
[/list]
Normal dodge eligibility, stamina and animation rules remain in effect. Stock attack/combo transitions can still end guard; a later dodge does not reactivate an ended guard ability. Release and press guard again in that case.

[b]Installation[/b]
Requires [url=https://www.nexusmods.com/thebloodofdawnwalker/mods/18]UE4SS for Dawnwalker[/url]. Install the ZIP through Vortex, select [b]Root (game folder)[/b], then enable and deploy.

For manual installation, copy the ZIP's Dawnwalker folder into the game root, preserving all subfolders. The native dodge asset and the UE4SS timing script are both required. Data contains only a package layout note.

[b]Settings[/b]
On first launch, the mod creates your personal INI here:
[code]%LOCALAPPDATA%/Dawnwalker/Saved/Config/EasierParryUE4SS.ini[/code]
Add the settings you want to override under [General], then restart the game:
[code][General]
factor = 2.0[/code]
Use factor = 1.0 for vanilla parry timing. Native guard changes are always active while installed. The old dodgeInterruptsGuard setting is ignored and its console toggle is retired. The shipped EasierParryUE4SS.defaults.ini supplies any omitted settings; updates do not replace your personal file.

UE4SS console shortcuts apply immediately and save your choice:
[code]easierparry 3
easierparry off
easierparry on[/code]
Use easierparry on/off to enable/disable only the timing multiplier, or easierparry status to check settings. Direct INI edits require a restart.

[b]Updating and removing[/b]
Before upgrading from an older version, copy Scripts/EasierParryUE4SS.ini from the old mod to the personal path above if you have custom settings and no personal file yet. Close the game, disable the old entry and deploy, then replace/reinstall that entry through the installer as [b]Root (game folder)[/b] and deploy again. Redeployment alone keeps the old layout. Keep one enabled entry.

To uninstall, remove the mod through Vortex and deploy, or, for a manual install, remove its EasierParryUE4SS folder under ue4ss/Mods and its three zzz_EasierParryUE4SS_P containers under Dawnwalker/Content/Paks/~mods. Personal settings remain.

[b]Compatibility and source[/b]
Native assets target Steam build 25129649 / CL-257186. Replaces GA_Input_CombatBlock and GA_Dodge. Choose one mod for each of these abilities; other parry timing overrides may also conflict. Controller Tweaks and Remap changes different assets and can remain enabled.

[b]Diagnostics[/b]
Set debugLogging = true under [General], or use easierparry debug on/off for this session, to capture bounded guard and timing diagnostics in ue4ss/UE4SS.log. Both are off by default. The retired guardTraceLogging key is ignored. Keep the log before another launch if testing fails.
